Сделаем сейчас ИИ claude основным и в чате добавим загрузку файлов(фото или другие документы)
в файлы нельзя добавлять со страницы файлов вручную, они будут только добавлять при загрузке в чате ИИ

Кэширование для экономии токенов
Если пользователь загрузил файлы и задаёт несколько вопросов — используй Prompt Caching чтобы не передавать файлы повторно:
python{
'type': 'document',
'source': { 'type': 'base64', ... },
'cache_control': { 'type': 'ephemeral' } # <-- кэш на 5 мин
}
Повторные запросы с теми же файлами обходятся ~90% дешевле.

Важные ограничения

Максимум ~20 изображений в одном запросе
Максимальный размер изображения: 8000x8000 px, 20 MB
Максимальный размер PDF: 32 MB
Claude не ставит диагнозы — только объясняет данные
Для HEIC (фото с iPhone) нужна конвертация на бэкенде
может делать мета данные дял каждого файла типа о чем он чтобы ИИ мог ориентироваться сам какой использовать потом03:31Да, отличная идея — это называется документ-индекс или file manifest.
Схема такая:
Шаг 1 — при загрузке файла сразу отправляешь его в Claude с вопросом:
python"Кратко опиши этот документ в 1-2 предложениях: что за документ, дата если есть, ключевые показатели или тема."
Шаг 2 — сохраняешь описание рядом с файлом:
json{
"file_id": "abc123",
"filename": "анализ_кровь.jpg",
"uploaded_at": "2026-03-10",
"description": "Общий анализ крови от 05.03.2026. Повышен лейкоциты (12.5), остальные показатели в норме."
}

**Шаг 3 — когда пользователь задаёт вопрос, в system prompt подставляешь индекс:**
У пользователя есть следующие документы:

анализ_кровь.jpg — Общий анализ крови от 05.03.2026. Повышены лейкоциты.
выписка.pdf — Выписка из больницы после госпитализации 01.03.2026.
мрт_голова.jpg — МРТ головного мозга от 2025 года, без патологий.
Используй нужные документы для ответа на вопрос пользователя.
Шаг 4 — Claude сам решает какие файлы подгрузить и ты отправляешь только их, не все сразу.
Это экономит токены и ускоряет ответы когда файлов накопится много.
